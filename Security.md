# Security Policy

## Supported Versions

Currently, the SkillOS Portal is in the prototype phase for the Smart India Hackathon (SIH 2026). As such, only the current `main` branch is receiving active updates and security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of government and user data very seriously. Because this project is intended for official use, we ask that you **do not** publicly disclose any security vulnerabilities you may find.

If you discover a security vulnerability within the SkillOS Portal, please follow these steps:

1. **Do not create a public GitHub Issue.**
2. Email your findings to the core maintainers (refer to the hackathon team lead contact).
3. Provide a detailed description of the vulnerability, including steps to reproduce the issue.
4. Include any potential impact on the local LLM integration or database integrity.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to provide a timeline for a fix. Thank you for helping keep the platform secure!
