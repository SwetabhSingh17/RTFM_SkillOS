# LMS Dashboard Builder Skill

This skill guides the development of the frontend and backend infrastructure for the AI-enabled Learning Management System.

## Learner Dashboard Requirements
- **Overview**: Display current competency levels, learning hours, and overall progress.
- **Skill Gaps & Recommendations**: Clearly visualize identified skill gaps and present AI-recommended learning paths (iGOT & NSSTA).
- **Assessments**: Interface for taking AI-generated quizzes and viewing instant feedback/explanations.
- **Virtual Assistant**: Integrate an AI-powered chat interface for learner support.

## Administrator Dashboard Requirements
- **Workforce Insights**: Aggregate data to show organization-wide workforce competencies and distribution.
- **Training Effectiveness**: Monitor the impact of completed trainings on competency improvement.
- **Predictive Analytics**: Visualize emerging skill requirements and future capacity-building needs based on trends.

## Technical Standards
- **Architecture**: Secure, scalable, cloud-ready, and interoperable.
- **Authentication**: Role-based access control (RBAC) and Single Sign-On (SSO).
- **Frontend Style**: Use functional React components and Tailwind CSS (as per global style guide), ensuring a modern, responsive UX.
- **Compliance**: Adhere strictly to data privacy and security mandates for government applications.
